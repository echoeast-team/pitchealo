Carmen Sans (Studio Jaso) is a commercial font, so it isn't included here.

The site uses it for headings in either of these cases:
1. Carmen Sans is installed on the computer (the browser picks it up automatically), or
2. You place your licensed web font files in this folder with these names:
   CarmenSans-Regular.woff2, CarmenSans-Medium.woff2, CarmenSans-SemiBold.woff2,
   CarmenSans-Bold.woff2, CarmenSans-ExtraBold.woff2   (.woff also works)

Headings use weight 600 (SemiBold), so that one matters most.
Until then, headings fall back to Figtree.
